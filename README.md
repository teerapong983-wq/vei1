# VEI1 Log

ระบบบันทึกข้อมูลการเดินเครื่อง โรงไฟฟ้าชีวมวล VEI1
**บริษัท วนชัย เอ็นเนอร์ยี่ จำกัด (Vanachai Energy Co., Ltd.)**

ที่เก็บนี้บรรจุเฉพาะ "เปลือกแอป" (หน้าเปิด + ไอคอน) สำหรับให้พนักงานของบริษัท
ติดตั้งเป็นแอปบนมือถือ ข้อมูลและตรรกะการทำงานทั้งหมดอยู่บนระบบภายในของบริษัท
