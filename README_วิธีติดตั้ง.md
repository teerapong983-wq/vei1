# VEI1 Log — วิธีทำให้เปิดเต็มจอเหมือนแอป (PWA บน GitHub Pages)

ไฟล์ในโฟลเดอร์นี้คือ "เปลือกแอป" 8 ไฟล์ ไม่มีข้อมูลโรงไฟฟ้า PIN หรือรายชื่ออยู่ข้างใน
ข้อมูลทั้งหมดยังอยู่ใน Google Sheet และ Apps Script เหมือนเดิม

- `index.html` — หน้าเปลือก ฝังลิงก์ฟอร์มไว้ข้างใน (บรรทัด `var APP_URL = "…"`)
- `manifest.json` — บอกมือถือว่าให้เปิดแบบเต็มจอ ชื่อแอป "VEI1 Log" สีเขียว VEI
- `sw.js` — ตัวช่วยให้ Android เสนอ "ติดตั้งแอป" (ไม่แคชข้อมูลจาก Google)
- `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png`, `favicon.png` — ไอคอนแอป

---

## ขั้นที่ 1 — Deploy Apps Script ใหม่ก่อน (สำคัญ ต้องทำก่อนเสมอ)

หน้าเปลือกจะฝังฟอร์มไว้ข้างในได้ก็ต่อเมื่อ Apps Script อนุญาต
ไฟล์ `VEI1_AppsScript_v3.gs` เวอร์ชัน **v6.43** เพิ่มการอนุญาตนี้ไว้แล้ว

1. เปิดโปรเจกต์ Apps Script → ไฟล์ **Code** → วางเนื้อหา `VEI1_AppsScript_v3.gs` ทับของเดิม → Save
2. **Deploy → Manage deployments → ดินสอ (แก้ไข) → Version: New version → Deploy**
3. ลิงก์ `/exec` ไม่เปลี่ยน ไม่ต้องแก้อะไรในหน้าเปลือก

> ถ้าไม่ทำขั้นนี้ เปิดหน้าเปลือกแล้วจะเห็นพื้นที่ว่าง เพราะ Google ปฏิเสธการฝัง

## ขั้นที่ 2 — อัปโหลดขึ้น GitHub (ทำครั้งเดียว ~10 นาที)

ใช้บัญชี **teerapong983-wq** ที่มีอยู่ ไม่ต้องลงโปรแกรมอะไรในเครื่อง

1. เข้า github.com → ปุ่มเขียว **New** (มุมซ้ายบน ข้างคำว่า Top repositories)
2. **Repository name** ใส่ `vei1` — เลือก **Public** — ติ๊ก **Add a README file** — กด **Create repository**
3. ในหน้าที่เก็บ กด **Add file → Upload files**
4. ลากไฟล์ทั้ง 8 ไฟล์จากโฟลเดอร์นี้ลงไป (ไม่ต้องลาก README นี้ก็ได้) → กด **Commit changes**
5. ไปแท็บ **Settings** (ด้านบนของหน้าที่เก็บ) → เมนูซ้าย **Pages**
6. หัวข้อ **Build and deployment** → Source เลือก **Deploy from a branch** → Branch เลือก **main** และโฟลเดอร์ **/ (root)** → **Save**
7. รอ 1–2 นาที แล้วรีเฟรชหน้า Pages จะขึ้นลิงก์:

```
https://teerapong983-wq.github.io/vei1/
```

นี่คือลิงก์ใหม่ที่จะแจกพนักงานแทนลิงก์ยาว ๆ ของ Google

## ขั้นที่ 4 — วิธีติดตั้งบนมือถือ (ส่งข้อความนี้ให้พนักงาน)

**Android (Chrome)**
เปิดลิงก์ → กดเมนู ⋮ มุมขวาบน → "เพิ่มไปยังหน้าจอหลัก" หรือ "ติดตั้งแอป" → กดติดตั้ง

**iPhone (ต้องใช้ Safari เท่านั้น)**
เปิดลิงก์ใน Safari → กดปุ่มแชร์ (สี่เหลี่ยมมีลูกศรขึ้น ตรงกลางล่าง) → เลื่อนหา "เพิ่มไปยังหน้าจอโฮม" → กดเพิ่ม

จะได้ไอคอนสีเขียว **VEI1 Log** บนหน้าจอ กดแล้วเปิดเต็มจอ ไม่มีแถบ URL

> หน้าเปลือกจะขึ้นคำแนะนำติดตั้งให้เองอัตโนมัติเมื่อเปิดครั้งแรก
> ถ้ากดลิงก์จากใน LINE จะขึ้นปุ่ม "เปิดใน Chrome / Safari" ให้ก่อน เพราะใน LINE ติดตั้งแอปไม่ได้
